## 💡 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas** e estudante da **42 São Paulo**, com foco no desenvolvimento de software e interesse especial por **Backend, Python, C, SQL e automação de processos**.

Gosto de entender não apenas *como* uma aplicação funciona, mas também **por que ela funciona daquela maneira**, explorando algoritmos, estruturas de dados, gerenciamento de memória, bancos de dados e arquitetura de sistemas.

Atualmente estou construindo projetos que conectam meus estudos com problemas práticos, buscando evoluir principalmente em:

- 🐍 Desenvolvimento Backend com Python
- ⚙️ Automação de processos
- 🔌 Desenvolvimento de APIs
- 🗄️ Banco de dados e SQL
- 💻 Programação em C
- 🧠 Algoritmos e estruturas de dados
- 🐧 Linux e fundamentos de sistemas
- ☁️ Cloud e DevOps

> **Meu objetivo:** transformar problemas em soluções de software simples, eficientes e bem estruturadas.
